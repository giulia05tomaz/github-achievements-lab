# Objetivos do laboratório

Este repositório reúne exercícios pequenos e verificáveis de desenvolvimento.

1. Representar valores em centavos para evitar somas com frações decimais.
2. Rejeitar valores negativos, fracionários e totais fora do limite seguro de inteiros.
3. Usar tipagem estrita e testes automatizados.
4. Praticar Issues e Pull Requests com alterações técnicas reais.

As despesas do exemplo são fictícias. Nenhuma integração financeira está prevista.
